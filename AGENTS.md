# Правила работы над этим проектом

## Рабочий процесс (важно соблюдать всегда)

1. Код пишем **только на компьютере** (в папке этого репозитория).
2. Локально **проверяем и тестируем** код.
3. **Коммитим и пушим** всё в GitHub.
4. Сервер **автоматически синхронизирует код** из GitHub (poll каждую минуту) и пересобирает Docker-контейнер.
5. Тестируем уже на сервере. Ассистент может тестировать на сервере сам.

## Стек

- Страницы: статический HTML, раздаётся через **nginx**.
- Каждый сервис живёт в **отдельном Docker-контейнере**.
- Первый сервис: `reels-finder` — открывается на `http://localhost:8080`.

## Каталог проекта

- `index.html` — страница.
- `Dockerfile`, `nginx.conf`, `docker-compose.yml` — сборка и запуск контейнера.
- `deploy.ps1` — скрипт развёртывания на сервере (pull + build + restart).
- `scripts/setup-docker.ps1` — одноразовая установка WSL2 + Docker Desktop (запускать от администратора).
- `scripts/install-autodeploy.ps1` — регистрация автосинхронизации в планировщике Windows.

## Автодеплой

Серверная папка — отдельный клон репозитория: `D:\reels-server\app`.
Планировщик Windows каждую минуту запускает `deploy.ps1`, который:
проверяет наличие новых коммитов на GitHub → тянет их → пересобирает контейнер (`docker compose up -d --build`).

Ничего не менять на сервере руками — только через git push.
